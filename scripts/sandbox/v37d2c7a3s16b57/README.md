# MyWay S1.6B.5.7 — learner-centred simulated interactive teaching

**Research-only, add-only.** Source baseline S56-R1, S56, S55-R1, S55, S54 remains unchanged. No SQL, DB writes, production routes, Git commit/push, Vercel deploy, real rendering, or authorized memory mutations.

## What it adds

- Optional Model B interactive scene planning on research turn **J3-2**. It may decline to offer a scene; scene support is explicitly a single **chemiosmosis mitochondria vs chloroplast** template, not a generic 2D/3D engine.
- A declarative scene payload (`myway_s57_scene_contract_v1`) with 2D or 3D camera projection, normalized geometry, labeled compartments, ATP-synthase nodes, draggable proton-marker targets, directed pathway choices, task prompts, allowed transitions, and accessibility expectations. **It does not render** a view, animate physics, or provide a production UI.
- A synthetic learner can accept or decline, select four control responses, explain, request hints, and retry after tutor feedback. In paid `--learner model` mode these choices are generated by GPT-4.1 mini **without the private scoring map**; in offline mode choices are author-written, explicitly not real learner data.
- An independent deterministic mechanism key scores selected compartments and flow paths. It does not evaluate whether the learner understands anything outside this specific synthetic task. Model A can interpret observable task evidence separately; the next Model B response receives the evidence so teaching can adapt.
- Provisional, learner-centric hypotheses about differential mitochondrial/chloroplast task performance, and provisional teaching-approach signals. A correct second answer after feedback is **not evidence that visuals caused improvement**, and one interaction never establishes a learning style or stable preference. Model C's preexisting root routing is preserved, not redesigned.
- Separately saved scene proposals, interactive evidence, the full transcript, and a JSON trace. No scene IDs or decisions are persisted to actual Learning Space.

## Design limits / next step

This prototype tests a **single** learning task and its evidence flow. It does not independently detect general root problems during scenes, identify causal learning preferences, establish long-term retention, validate scientific content outside the authored mechanism key, or prove that 2D/3D rendering is feasible. Next work should assess authenticity of learner behaviours and relationship/personalization inference from repeated independent observations before modifying production Learning Space.
