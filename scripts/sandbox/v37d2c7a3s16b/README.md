# MyWay S1.6B — Longitudinal Learning Space Review

## Scope and purpose

Research-only, additive companion to the previously installed S1.6A synthetic simulator. Reuses `s16-space-sim.mjs` unchanged. Never edits the actual Learning Space, Supabase, cloud services, original v1 or user memory.

The journey uses the existing 12 synthetic topics and 36 historical root-problem records, and reorders eight seed turns into one learner's repeated visits:

`T01 → T07 → T10 → T02 → T06 → T08 → T15 → T11`

This is a scripted chronological scenario (not learner responses generated by Model B). Offline mode contains no real model answers. Model mode invokes the same real GPT-4.1 mini A → B → retrieval → C research chain as S1.6A, with real 384-D local MiniLM embeddings and an evolving in-memory synthetic history. Model A currently assesses each statement independently and does not receive the full dialogue transcript. This is **longitudinal memory continuity**, not fully stateful conversational intelligence.

## What it adds over S1.6A

- An independent `LONGITUDINAL_REVIEW.txt` for Notepad, showing each original learner message, actual teacher output where present, per-turn memory and retrieval evidence, a human-review rubric and final state.
- Explicit results compared with hidden synthetic reference labels, without sending expected labels to models. These are **test-case labels**, not independently adjudicated gold truth.
- An explanatory semantic-rival watchlist. High historical similarity between subjects is **not** automatically treated as a relationship. Existing explicit-comparison relationship hypotheses stay `unverified`.
- A correction/reversibility control: `--inject-fault` in offline mode deliberately mislinks T07, records the later T10 alarm, and (where detected) constructs a nonapplied restoration plan using known fault-injection provenance. It **does not demonstrate autonomous repair**.
- No new endpoint, model type, pricing table, SQL, background job, active browser prompt, proxy rule or schema migration.
