# MyWay S1.6B.5.2 — Evidence-Grounded Teaching and Realism Benchmark

Additive research-only patch to the separate `v1-learning-experiment` worktree. **No new model prompt, API route, production deployment, database changes, persistent memory changes or personalization writer.** The original S1.6B.5 and S1.6B.5.1 teacher voices remain unchanged and separately selectable. The existing Model B local endpoint is used only in explicitly authorized paid mode.

## What is included

- 10 authored, **synthetic** multi-turn conversation scripts across 9 learning domains, with exactly 48 learner-turn snapshots. This is not a sample of actual observed learner behavior.
- Explicit raw previous learner and scripted tutor utterances, with byte-for-byte historical evidence checks. No author-written root-problem summary is disguised as a learner utterance.
- 36 development snapshots and 12 pre-labeled holdout snapshots. Holdouts require `--unlock-holdout`; labels are still researcher-authored and **not** independent expert verification.
- Seven instructional actions represented. Messy follow-ups, deictic pronouns, reported versus expressed reasoning, corrections, incomplete clarifications, requests to check understanding, typos/colloquialisms, cross-turn topic revisions and practical examples.
- Two evaluation conditions: **oracle** (researcher-provided intent/focus/action guidance) and **inferred** (existing S1.6B.3 heuristic intent plus S1.6B.4C deterministic planner with focus=auto). Inferred mode is **not** an end-to-end test of production Model A routing or long-term memory.
- Human-review reports with raw synthetic dialogue and evidence, a masked review sheet, CSV scorecard and separately generated answer key; none contain prefilled learning-quality scores.

## Interpretation guardrails

- An action match is agreement with a researcher-authored reference, not evidence of correct real-world routing. `SAFE_HOLD` for missing exact history can be preferable to guessing.
- Scripted assistant messages are not generated by Model B, nor are successive simulated turns actual feedback to a previous model output. Thus this is **multi-turn context replay**, not closed-loop adaptive teaching.
- Intent inference is a limited historical heuristic. The test does not exercise real Model A, production storage or the live UI.
- Real-world representativeness remains **unverified** until consenting learners, independent annotators and privacy-reviewed collection protocols are added. The fixture wording must not be optimized against holdouts after inspecting them.
