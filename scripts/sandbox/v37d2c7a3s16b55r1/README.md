## What changes in the separate `s16b55r1` runner

1. **Narrow explicit distinct-mechanism rule**: The researcher-authored oxygen question is recorded as a *provisional distinct root*, not automatically merged into a root about carbon atoms. Distinction requires a verbatim quote, explicit separate-question intent, an independently recognizable mechanism signature, all eligible same-topic anchors differing, and low lexical overlap. This is a deliberately narrow fixture rule, not general semantic comprehension. Existing Model C guesses of `same` or `refinement` that contradict recognized mechanisms are held rather than written.
2. **Evidence ledger + unresolved holds**: Every synthetic learner turn now creates a provenance-bearing evidence observation, including a bounded verbatim excerpt and full-message SHA-256, without asserting mastery. Distinct pending holds and check-request commitments survive a serialized in-process session boundary. No full tutor dialogue or `turns` array is serialized in the resumed snapshot. Full cold-start persistence or real DB retrieval is not claimed.
3. **Selective visuals**: An explicit request produces one focused, unrendered diagram proposal. Merely mentioning a diagram creates no proposal. `Before a diagram, please check my reasoning` defers the existing request rather than creating another.
4. **Topic-level relationship hypotheses**: The mitochondria/chloroplast comparison may justify a provisional topic-level chemiosmosis hypothesis, but not a historical learner-root-to-root relationship. Explicitly `root_relation_supported=false` and no graph writes.
5. **Regressions**: Paired resumed/full-history offline runs, tutor-reply branch changes, persistence of a synthetic hold, precision/negative identity and visual controls, JSON-schema and usage/cost guards with an in-memory mocked provider. No paid calls in installation/tests.

## Research limitations

- `S1.6B.5.5-R1` still uses researcher-authored synthetic learner turns; contingent rules are finite and not a validated learner simulator.
- Offline A/B are authored, C is a lexical baseline plus **narrow author-defined mechanistic distinctions**. Neither model quality nor learner benefit is established.
- This patch preserves *provisional* memory within a research process; it does not implement durable database writes, production memory, cross-session authentication or MiniLM vector retrieval.
- An unanswered check request is carried forward as an **unverified request record**, not as a mandatory teaching action; a human must evaluate whether an earlier reply satisfied it.
- A topic-level biological analogy is not evidence of the learner actually transferring knowledge between roots.
- Visuals are textual proposals only; no imagery is generated.
