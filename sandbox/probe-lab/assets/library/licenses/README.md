# MyWay asset license reviews

Each public runtime asset requires an explicit JSON review.

BlendKit intake is restricted to exact CC0 results. Royalty Free assets are
blocked from standalone public GLB distribution.

Generic CC BY and CC BY 4.0 are separate registry values. Both require a
structured attribution record containing the exact supplied credit, source
page, stable source asset ID, licence name, and modification notice. Generic CC
BY must not be silently upgraded to a numbered version. Promotion remains
blocked until the formal review preserves and approves the same attribution.

TRELLIS outputs remain sandbox-only until production-use and public-distribution
terms are independently confirmed.
